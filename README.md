# Hey, I'm Ahmed 👋

I'm the guy you call when the numbers don't match.

I live in the part of data work nobody puts on a slide: pulling records out of an ERP, fixing what's broken underneath, and shipping a report that finance and the warehouse read the same way. Then I make sure it still works at 3 AM.

**Two layers, every time:**

| 👔 What the business sees | 🔧 What holds it up |
|---|---|
| One clean number. One answer. A dashboard people actually open. | Pipelines that only move what changed, retries, logging, typed clients, tests, backups I actually check. |
